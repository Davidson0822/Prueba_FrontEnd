# 📦 Sistema de Inventario - Frontend

¡Bienvenido al repositorio del Frontend de nuestro sistema de gestión de inventario! Este proyecto es la interfaz de usuario que se conecta con nuestra API de inventario para ofrecer una experiencia intuitiva, rápida y visual al gestionar productos, stock y reportes.

---

## 🚀 Características Principales

*   **Dashboard General:** Vista rápida del estado del inventario.
*   **Gestión de Productos:** Creación, edición, eliminación y visualización detallada de ítems.
*   **Control de Stock:** Entradas y salidas de mercancía en tiempo real.
